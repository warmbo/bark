# Bark AVC Project

Hermes: when working in this repo, follow these rules.

## Project Context
- Bark is a Discord bot with modular architecture. The `auto_voice` module replicates AVC's dynamic temporary-voice-channel behavior.
- Primary codebase: `/home/cody/Projects/bark-avc`

## Verification
- Always run `python -m pytest --tb=no -q` before declaring changes done.
- Target: 142+ tests pass, 0 failures.
- Run `git diff --check` to catch whitespace errors.

## Conventions
- Use `uv run pytest` or direct `python -m pytest` (venv active).
- New modules need tests. Match existing test patterns.
- Logging: use the built-in Bark logger, not print().
- Event handlers: snapshot `before.channel` and `after.channel` before any await to avoid discord.py's cached VoiceState mutation bug.

## Deployment
- The bot runs on hermes-core (CT1115). Restart the systemd service after deploying.
- Changes go through: implement → test → code review subagent → commit with `[verified]` prefix → deploy.

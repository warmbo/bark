What is Bark?

A single process that runs both the Discord bot and the management dashboard — no microservices, no complex infrastructure.

Bark pairs a discord.py bot with a FastAPI web dashboard in one async Python process, so server operators can moderate, configure, and monitor their communities from the browser. The dashboard uses Discord OAuth2 for authentication, server-sent events for live updates, and a glassmorphism design system with role-gated pages. Every feature — moderation, reputation, roles, auto voice, logging, welcome — is a pluggable module that can be enabled, configured, and reloaded per server without restarting the bot.

Bark Privacy Policy

Last updated: 2026-08-29

This Privacy Policy explains how Bark (the "bot", "we", or "us") handles data when you use it to manage a Discord server. Bark is a self-hostable Discord management bot; the person or organization running an instance ("instance operator") controls how that instance is configured and deployed.

1. What we collect

When you invite Bark to a server and use its features, the instance stores only the data needed to provide those features, including:

  • Discord identity data required for the dashboard login (your Discord user ID, username, avatar, and the servers you share with the bot) — collected via Discord OAuth2 with the identify and guilds scopes.
  • Server configuration you choose to set (module settings, moderation rules, reputation tiers, announcement content, etc.).
  • Moderation records created through the bot's moderation features (warnings, cases, notes, timeouts).
  • Reputation/level data (scores, levels, tiers) if you enable the reputation module.
  • Activity statistics derived from Discord events (message counts, voice time) needed for the dashboard's analytics, retained in aggregate form.

We do not collect message content for any purpose other than the features you enable, and we never sell personal data.

2. How data is stored

Data is stored in a local SQLite database on the instance operator's own hardware. The instance operator is responsible for its backup, security, and retention. We store Discord OAuth access tokens only transiently to complete login, and never log tokens or secret keys.

3. How data is used

  • To provide the features you enable (moderation, reputation, roles, announcements, voice insights).
  • To operate and secure the dashboard (login, access control, rate limiting).
  • To generate aggregate statistics shown in the dashboard.

4. Data sharing

Bark does not sell or share your data with third parties. Data is processed solely by Discord (for the bot's normal operation) and the instance operator. Anonymous, aggregate statistics may be used for operational purposes.

5. Data retention & deletion

You can remove Bark from a server at any time, and the instance operator can delete the stored data. To request deletion of specific data, contact the instance operator. Server owners can disable modules or reset reputation/moderation data through the dashboard.

6. Children's privacy

Bark is not directed at children under 13. We do not knowingly collect personal information from children under 13.

7. Contact

For privacy questions, contact the instance operator running the Bark instance you use.

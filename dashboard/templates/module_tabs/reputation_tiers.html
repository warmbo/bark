{{ icon("shield-half", 16) }} Reputation Tiers

Link each tier to a Discord role — members get the role automatically when they level up. Higher tiers can then be granted access to more channels.

Set channel permissions in Discord for each linked role to control access — the tier role is the access role, and roles are only ever granted, never revoked. Keep tier roles above roles that restrict channels, and above the bot's highest role, so the bot can assign them.

Auto-assign: when checked, the bot grants the linked role automatically the moment a member reaches this tier's level. When unchecked, the role link is informational only — nothing is assigned. Roles are never removed automatically.

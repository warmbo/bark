{{ icon("badge-check", 16) }} Role Rules

Rules that automatically assign or release roles. Each rule watches one trigger; when the trigger is true the role is added, and when it stops being true the role is removed.

{{ icon("book-open", 14) }} How each rule type behaves
{{ icon("user-plus", 15) }}
Welcome

When a member joins the server, the role is added immediately. The role is never removed automatically — it is a one-way welcome grant.

{{ icon("calendar-days", 15) }}
Tenure

When a member has been in the server for at least the configured number of days, the role is added. The module checks every few minutes and grants the role to anyone who has crossed the milestone since the last check.

{{ icon("headphones", 15) }}
Voice

While a member is connected to any voice channel, the role is added. As soon as they leave (or disconnect), the role is removed. Useful for "in call" badges.

{{ icon("radio", 15) }}
Stream

While a member is live on Twitch, the role is added. When their stream ends or they switch to a different activity, the role is removed. Bark detects this from the member's Discord presence — the member must have linked their Twitch account to Discord. Streams on other platforms (e.g. YouTube) do not trigger it.

{{ icon("smile", 15) }}
Reaction

Members react to a message with the configured emoji to claim the role themselves. Un-reacting removes it. You can scope the rule to a single pinned message (by message ID) or let any message in the channel work. Supports both unicode emoji (🎮) and custom server emoji (<:name:1234>).

Note: the bot can only manage roles that sit below its own highest role in the server's role list. Rules pointing at a higher role are skipped, and a warning is logged instead of failing.

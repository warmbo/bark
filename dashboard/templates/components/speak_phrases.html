{{ icon("message-square", 16) }} Speak Phrases

Preset phrases members can trigger with /{{ command_group_name }} speak <key>. Anyone in the server can use them; only admins (or anyone granted via this module's Role Access) can edit them.

Keys are short tokens like word1 or phrase2 — members type /{{ command_group_name }} speak word1 to trigger the phrase. Deleting a key's text removes it.

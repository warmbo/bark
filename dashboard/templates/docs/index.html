Quick start

Bark is a dashboard-first server manager. Command it from Discord with a single slash command: type /{{ group }} and pick a module, then a command — e.g. /{{ group }} moderation warn or /{{ group }} stats.

  • /{{ group }} help — a DM with the full guide.
  • /{{ group }} help <command> — detailed help for one command.
  • Info commands are private by default; add public as the last argument to post them for everyone, e.g. /{{ group }} leaderboard public.

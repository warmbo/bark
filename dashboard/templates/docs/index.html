Quick start

Bark is a dashboard-first server manager. Run it from this dashboard, and command it from Discord with one slash command: /{{ group }} <command> [args...]. A bare /{{ group }} shows every available command.

  • /{{ group }} help — a DM with the full guide.
  • /{{ group }} help <command> — detailed help for one command.
  • Info commands are private by default; add false as the last argument to post them for everyone, e.g. /{{ group }} leaderboard false.

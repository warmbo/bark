Permissions

Bark grants access in three tiers. A user's effective role is the most permissive they hold (server owner, Discord admin, configured staff role, or per-module override).

Anyone

Every member of a server where Bark is installed. Info commands (help, info, leaderboard, reputation, roles…) and self-service commands (voice, thanks) are available here.

Moderator

Members holding a moderation permission (kick, ban, timeout, moderate members…) or a configured staff role. Can warn/kick/ban/timeout, manage moderation, and post announcements where the module allows.

Admin

Server owner, Discord ADMIN/MANAGE permissions, or the instance owner. Can change server state and configuration, manage modules, and access instance settings.

Rules of thumb

  • Commands that only show information are available to all members.
  • Commands that change anything (moderation actions, config, announcements, role management) require Moderator or Admin.
  • Every action has a documented role — see the table below.
